---
# 目标
写一篇有真实时政依据、跟本人工作对得上的思想汇报（每篇约2000-2500字），交付 Word 文档。

# 步骤
1. **确认范围**：汇报人姓名、单位和支部、覆盖的时间段、落款日期、现在处于哪个阶段（积极分子/发展对象/预备党员）。
2. **收集本人材料**：在用户电脑或网盘里搜以前的思想汇报、工作总结、个人简介、事迹材料、简历、整改材料。按时间段提取：主要工作、成效数据、荣誉、学习进修情况、存在的不足。只用材料里有的事实，不编数字和奖项。
3. **查时政原文**：去新华网、人民网、中国政府网、求是网，按覆盖期查重要内容，包括中央政治局会议和集体学习、全会、重要讲话、回信、考察、《求是》文章、党内学习教育、重要纪念日（五四、七一、国庆等）。凡是加引号的话，都要跟原文逐字核对；还没开的会写成"即将召开"。
4. **列提纲**（每篇选3到4个时政主题）：
   - 开头：称谓"敬爱的党组织："，交代本期的学习情况。
   - 主体：每个主题一段，写法是"学了什么（准确引用）→ 我的认识 → 对照本职工作的具体做法和成效"。
   - 不足与改进：2到3条，要具体、要诚实，可以写材料里如实记录的问题和整改情况，并注意时间点跟覆盖期对得上。
   - 结尾：今后打算、请党组织监督，然后"此致 敬礼！"、汇报人、日期。
5. **成文排版**：标题"思想汇报"用方正小标宋二号，正文用仿宋_GB2312三号，A4纸、公文页边距、加页码。
6. **交付**：给出文件路径，列出引用了哪些时政内容和来源，以及需要用户确认或补填的地方。

# 注意
- 不编讲话原文、日期、奖项、职务。没有依据的地方标【待填】或【待核】。
- 个人业绩如果是团队成果，写成"参与""推进"，不要写成本人独立完成。
- 涉密、内部的信息不写进文稿。
